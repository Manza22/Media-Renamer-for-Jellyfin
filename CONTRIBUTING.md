# Contributing

Thank you for helping improve Media Renamer. This project is **open source** under the [MIT License](LICENSE).

## How to contribute

1. **Fork** the repo and create a branch.
2. Make focused changes (one bug or feature per PR when possible).
3. Test locally: `pip install -r requirements.txt` and `python media_renamer.py`.
4. Open a **pull request** with a short description and screenshots if UI changed.

## What we welcome

- Bug fixes (matching, paths, Windows filename edge cases)
- Clearer UI text and error messages
- Documentation improvements
- Tests in `tests/`

## What we will not merge

- Code that phones home, installs without consent, or bundles unrelated executables
- Features whose primary purpose is piracy or bypassing content rights
- Changes that remove or obscure the MIT license

## Security

If you find a security issue, open a GitHub issue with details or contact the maintainer privately. Do not publish exploit code aimed at harming users.

## Forks and rebranding

MIT allows forks. If you ship a public fork with different behavior, use a **distinct name** and document that it is not the official Media Renamer build.
